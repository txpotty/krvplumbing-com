    An air switch puts a push button on the countertop or sink deck instead of a wall switch. Pressing it sends air down a tube.     Standard InSinkErator Installation in Derby

    A standard install replaces the unit under an existing sink. We take the old disposal down, scrape the old putty off the flange and set a new flange with fresh putty. Then the mount ring goes on. Power comes from a cord kit or the existing hardwire, checked for ground before the breaker goes back on.
