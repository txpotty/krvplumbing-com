    Badger Replacement for Salina Homes

    Builder-grade kitchens almost always started with a Badger, and a worn one usually gets replaced with another. First the old unit comes off. A matching quick-lock mount in good shape can stay, which saves time and keeps a seal that already fits the sink. The new Badger goes up and gets tested.

    Commercial Disposer Installation in Salina, KS

    Restaurant disposals are a different class of machine. Commercial units run 1 to 5 HP, usually on a dedicated circuit, and many need a water solenoid and a control panel mounted on the wall. We set the unit, plumb the water feed and coordinate with the electrician on the circuit. Expect an inspector to check it. Local code may also limit where a disposer can discharge relative to the grease interceptor, so we confirm that before the job starts.

    First-Time Disposal Installation in Salina

    Kitchens that never had a disposal need some rework. First, the sink gets a disposal flange. The tailpiece and trap have to be reworked, and the cabinet needs a switched outlet, which means an electrician if there is no power under the sink already. Drain slope to the stack gets checked as well.

    Septic-Friendly Disposal Installs in Salina, KS

    Homes on septic can run a disposal, but food solids add load to the tank. Septic systems are common across rural Kansas, and regular pumping helps prevent backups and drain field failure. InSinkErator's Septic Assist feeds an enzyme solution into the chamber during each run to start breaking down waste before the tank. We mount the cartridge and show you how to swap it. Scraping plates into the trash still helps.

    New Construction Disposal Installs in Salina

    New builds and gut remodels get the disposal in two trips. During rough-in, the drain stub height gets set and the electrician leaves a switched outlet in the sink cabinet. We hold the unit back for now. After the sink and faucet are set, we return to hang the unit, tie in the dishwasher and run the full water test.
