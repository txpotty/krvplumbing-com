    Home Tankless Flushing in Salina

    Many Kansas homeowners use water softeners to protect their tank water heaters and fixtures against heavy mineral buildup.     Tankless Error Code Diagnosis in Salina, KS

    An error code is the heater telling you what it saw. On a Rinnai an LC code means scale, on a Navien E003 means no ignition, and on a Noritz a 90 usually means an air or exhaust problem. We pull the code history before touching anything. If a part has failed, you hear the repair and the price before we start.

    Noritz Tankless Tune-Ups in Salina, KS

    Noritz builds a solid heater, but solid does not mean maintenance-free. We start a Noritz tune-up at the exhaust, checking for soot and any blocked termination. Then we check the fan and the combustion air path. Last, we check the temperature setting and run a few fixtures at once, which shows whether the unit holds temperature between back-to-back showers.

    Yearly Tankless Inspection in Salina
