    Switching to waterless is mostly a fixture swap.     Flushometer Urinal Installation in Olathe

    Manual flushometers are still the most common setup. We install Sloan Royal or Zurn AquaFlush valves on a 3/4 inch supply, adjust the control stop for proper flow, and set the vacuum breaker the right distance above the bowl so it protects the drinking water. Handles can go left or right. ADA units need the handle within reach.

    Urinal Installation Cost Factors in Olathe, KS

    Carrier work is the biggest cost swing.     Drainage and Venting for Urinals in Olathe, KS

    Urinal drains clog with scale, not paper. Low-flow and waterless units leave mineral buildup in the line, so proper slope and a cleanout matter. A proper vent keeps odor out. We tie in within code distance.

    Flush Valve Urinal Installation in Olathe, KS

    Flush valve urinals are the commercial standard. Tankless flushometers deliver a set volume from a 3/4 inch line and recover instantly for the next user. The volume matches the fixture rating. Wrong settings stain bowls.

    ADA-Compliant Urinal Installation in Olathe

    At least one urinal in a public restroom with more than one usually has to be accessible. ADA units need a rim at or below 17 inches, a 13-1/2 inch projection and 30 by 48 inches of clear floor. The flush handle has to be easy to reach. We mark it all during rough-in.
