    New Construction Sewage Ejector Pump Installation in Lenexa, KS

    On a new build, we set the basin ahead of the slab pour. That is the cheapest time, since there is no concrete to cut, and we stub the drains, the vent and the discharge to the plans so the rough-in inspection goes smoothly. Builders like the timing.

    Basement Bathroom Ejector Systems in Lenexa

    Basement bathrooms sit below the building sewer, so every fixture drains to a sealed pit instead of flowing by gravity. We cut the slab, trench the drain lines to the basin, set it, run a two-inch vent up through the house to the roof and pipe the discharge to the building drain with a check valve and shutoff. The slab gets repoured.

    Sewage Ejector Pump Basin Installation in Lenexa, KS

    The basin is where the system lives, and a 30-gallon size is common for a single basement bathroom. Bigger basins let the pump run longer, fewer times a day, which is easier on the motor and switch, so we size up when the pit serves a laundry or several fixtures. Every lid gets sealed.

    Liberty Pumps Installation in Lenexa

    Liberty ejector pumps show up on a lot of our installs, with cast iron bodies and two-inch solids handling on most sewage models. Liberty sells packaged systems with basin, lid, pump and check valve already matched, which means less field fitting and a listed assembly for inspection. A full-port valve gets added.

    Liberty Pumps Sewage Ejector Pump Installation in Lenexa, KS

    Liberty builds simplex and duplex packages that arrive with the basin, pump, lid and fittings matched. That speeds up new installs, and their wide-angle float switches are less likely to hang up on the basin wall than older tethered floats, which is one of the most common reasons a pump fails to start. Stuck floats are common.

    Ejector Pump Installation Cost Comparison in Lenexa, KS
